\# Structure du plugin block\_tutor\_ai



\## Fichiers obligatoires

\- `version.php` — métadonnées du plugin

\- `block\_tutor\_ai.php` — classe principale du bloc

\- `lang/en/block\_tutor\_ai.php` — traductions



\## Fichiers complémentaires

\- `db/access.php` — permissions

\- `styles.css` — style visuel du chatbot

\- `amd/src/chat.js` — comportement JavaScript

\- `templates/chat.mustache` — template HTML



\## Règle de nommage

Tout doit s'appeler `block\_tutor\_ai` — dossier, fichier PHP, classe.



\## Emplacement dans Moodle

`/var/www/html/blocks/tutor\_ai/`
